# 验收证据目录（2026-11-11）

本目录是 2026-11-11 独立验收与复查的原始材料，入库前已做**路径脱敏**：

- `outputs/`：两份报告（独立验收报告、复查报告），结论与判定原文保留。
- `work/`：原始日志、JSON 产物、临时复算脚本与 trace。

## 脱敏规则（替换前后一一对应）

| 被替换的内容 | 入库后写法 |
|---|---|
| 仓库根的盘符绝对路径及其下所有路径 | `<REPO_ROOT>`（日志/JSON）或相对仓库根的写法（文档与命令） |
| 操作系统用户目录（盘符下 `Users` 里的用户名那层及其子路径） | `<USER_HOME>` |
| 外部中医语料库根目录 | `<EXTERNAL_TCM_ROOT>` |
| 外部索引缓存目录 | `<EXTERNAL_INDEX_CACHE>` |
| 外部冲刺工作区根目录（vLLM / ASR 等实验产物） | `<EXTERNAL_SPRINT_ROOT>` |
| 本机模型目录 | `<LOCAL_MODEL_DIR>` |
| 仓库外任务书 `LexWeave_项目改造任务书.md`（位于个人目录） | `<EXTERNAL_TASK_BRIEF>` |
| Markdown 里的 `file:///` 盘符绝对链接 | 相对本文件的仓库内路径 |

替换是纯字符串级：**数字、结论、判定、证据强度均未改动**；JSON 与日志结构未变（`*.json` 全部可正常解析），
只是把本机路径换成了上表占位符，同一占位符出现的位置与替换前完全对应。

