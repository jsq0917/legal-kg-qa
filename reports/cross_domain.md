## 3. 迁不过去的法律域特有规则（7 条，含具体例子）

1. **法条号 / 条文体系**：劳动法的检索单元是「法条」，`article_id` 形如 `ll#82`，`eval_retrieval.py` 用 `expected_articles` + `article_citations` 算 R@5；中医文档的检索单元是百科页（`herb:草乌` / `formula:六君子汤`），**没有条号**，本次 82 条的式样从 `第X条` 变成 `中药/方剂名字`，条号相关字段 0 条。
2. **劳动法术语别名 / 实体链接词表**：`data/lexicon/concepts.jsonl`（280 个概念名 + 633 个别名）+ `alias_index.json` + `concept.faiss`。中医术语 12190 个与该词表交集 **0 个**；82 条题里 n_concepts=0 的比例 **100.0%**，即实体链接层在中医域整体空转。
3. **DEFINES 定义式证据规则**（`scripts/check_defines_edges.py`「是指/系指/所称/分句主语位+应当/不得/可以」）：本次机械校验命中 230 处证据，判为定义式/主语位（`normal`）**0 处**，`pending_semantic` 230 处。例：「草乌」在《草乌》页出现的是「【来源】为…」的百科描述，不是「本法所称…是指…」的法条定义，该规则在中医语体下 0 命中。
4. **域外拒答阈值 0.62**：该值由劳动法 60 条金标 top1 相似度的 5% 分位标定（`config.py`，`scripts/measure_off_domain.py`）。中医 82 条 top1 分布 min=0.6262 / p05=0.6668 / median=0.7090 / max=0.7924，低于 0.62 的 **0/82 条**。注意这与「误拒」相反：阈值在中医域**完全失去判别力**（全部放行 = 等于不设防），因为它标定的是劳动法语料的相似度分布，不是「中医问题是否域外」。
5. **五道闸里的法律合规闸**（`app/__007__agents/__001__gates.py`）：`cite_exists` 用 `_ARTICLE_TAIL=第[一二三四五六七八九十百千零〇0-9]+条` 校验引用，`_LAW_TAILS=劳动合同法/劳动法/民法典`；`cite_in_retrieval` / `path_support` / `evidence_span` 也全部围绕「法条引用 + 图路径」。中医答案没有条号，前四闸**无对象可校验**（直接判 fail）；医疗场景该闸应换成「不建议自行用药 / 就医提示」，而不是法条合规。
6. **路由标签体系与 LLM 路由提示词**（`app/__004__retrieval/__004__router.py`）：simple/medium/complex 按「问题点个数 + 是否跨法」定义，system prompt 明写「跨《劳动合同法》《劳动法》《民法典》两部以上 -> complex」。中医没有跨法概念。机械标签（单/双/三文档题）下诊断准确率 0.6585，其中 **complex→medium 20/20**（三文档题全被判成 medium，即 top_k 只给 5 不够用），`rule_fast` 覆盖率 0.4390。
7. **图 schema 与图检索路**：`app/__003__graph/__000__schema.py` 的节点/边（法条、概念、场景、DEFINES、CITES…）在中医域没有对应物；外部中医图谱（`tcm_metadata.json`）只有 6 labels / 6 relationships / **12 条样例三元组**，且是课程项目 LLM 抽取产物（非人工标注），不足以评测图路。因此**图路 = 不具备**，本次只跑文本三路。

## 4. 掉点分析（按问题类型）

| 类型 | 中医 R@5 | 劳动法同路 R@5 | 差值 | 主要失败原因 |
|---|---|---|---|---|
| 单文档（药材属性） | 1.0000 | 无对应（simple 为合成题） | — | 题面=实体名，28/28 全中 |
| 双文档（方剂+药材） | 0.8824 | 0.8333（two_hop） | +4.91 pt | 方剂页稳中，药材页被同名方剂页挤掉 |
| 三文档（方剂+两药） | 0.6333 | 0.7000（three_hop） | -6.67 pt | top-5 只装下 2 篇，漏 1 篇即掉 0.33 |

- 全部漏召 **30 次，100% 是药材页**（方剂页 0 次漏、药材页 30 次漏）。
- 失败机制是**同名词条竞争**，不是语义不匹配：问「方剂 F 含 药材 H」时，向量和 BM25 同时被「名字里含 H 的其它方剂」吸引，把 H 自己的药材页挤出 top-5。
- 例：`枳实消痞丸::厚朴` 漏召 `herb:厚朴`，rrf top-5 = `formula:枳实消痞丸`、`formula:厚朴三物汤`、`formula:厚朴七物汤`、`formula:栀子厚朴汤`、`formula:枳实薤白桂枝汤`（除第 1 名是查询里的方剂本身，其余都是名字里含该药材名的其它方剂页）。

- 总体相对劳动法同一文本路 +11.46 pt；但这 82 条题面含实体名，属**宽松口径**，跨域差值只能读作「管线未崩」，不能读作「中医更好」。
- 真正的域间差异是**文档粒度**：劳动法一条法条 = 一个短检索单元；中医一篇百科页承载多实体多关系，且实体名会出现在其它页里，top-5 预算更容易被同类条目挤爆。
