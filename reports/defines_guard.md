## 起点

100 条模型盲判（`data/eval_out/defines_human_labels.csv` 的抽样口径，`seed=20261030`；当时误标为“人工盲标”，
实际标注者是 AI agent，见同目录 `defines_human_labels.provenance.json`）判出
**49/100 = 0.49**，B1 目标 0.85，差 36pt。同一批 100 条两次模型判读分别是 0.49 与 0.6265，
说明这个数字不是「再判一遍」能动的，得看假边的形态。

## 假边只有两类形态

把 51 条判 0 的边按「命中串与概念是什么关系」拆开：

| 形态 | 条数 | 例子 |
| --- | --- | --- |
| 命中串被同一位置更长的**另一个概念**吞掉 | 13 | 「债权人」里的「债权」、「抵押权人」里的「抵押权」 |
| 命中串后面紧跟主体后缀（人/方/者/单位…） | 10 | 「担保人」里的「担保」（概念是担保物权） |
| 别名**不含概念中心语** | 8 | 用「业主」指「物业服务合同」、用「承运人」指「运输合同」 |
| 别名是**主体名词**却指非 entity 概念 | 2 | 用「受托人」指「委托合同」 |
| 纯 cue 口径问题（同分句闸门即可拦下） | 15 | 「订立借款合同，借款人应当……」 |
| 规则看不见的残留 | 3 | 见下 |

两点结论：① 别名词典比规则更容易出问题——24 条「别名≠概念名」的边里只有 1 条成立；
② 主语位判据本身没大错，错在「谁的主语」。

## 改动

`app/__002__extract/__003__edge_typing.py`，新增 `DEFINES_GUARD=1`（默认关闭，隐含开启 STRICT）：

1. `_maximal_term_reason`：命中串被更长词吞掉且该词属于**另一个**概念 → 否掉；
   命中串后紧跟主体后缀 → 否掉。「劳务派遣单位」里的「派遣单位」仍属本概念，不误杀。
2. `_alias_fidelity_reason`：别名必须保留概念名中心语（后两字）；主体名词不能充当非 entity
   概念的别名。
3. `_carry_over_subject`：承前省略补判——别名在分句首、模态词在下一分句，但两分句之间到
   模态词只剩「则/也/均/仍/还/都/即/亦」或什么都不剩时，主语仍是该概念
   （「定作人提供材料的，应当按照约定提供材料」）；中间冒出新的主语则照旧否掉
   （「定作人提供材料的，承揽人应当及时检验」）。样本里救回 2 条被同分句闸门误杀的真边
   （#22 劳动者、#29 定作人），全量新增 130 条 `carry_over` 边、未带入新的假边。

样例级断言见 `tests/test_defines_guard.py`（8 条正负例 + 1 条开关对照），`tests/` 全绿（71 passed）。

## 结果

| | 改前 | 改后（`DEFINES_GUARD=1`） |
| --- | --- | --- |
| 全量 `DEFINES` 条数 | 819 | 505（−314） |
| 100 条样本上仍判 `DEFINES` 的 | 100 | 47 |
| 其中判「成立」 | 49 | 44 |
| **精度** | **0.49** | **0.936**（Wilson95 0.87–1.00） |
| 召回（相对模型判 1 的 49 条） | 1.00 | 0.90 |

护栏没被杀掉的 3 条假边：`#36 出卖人`（「对……保留的所有权，未经登记，不得对抗」——主语实为
所有权）、`#67 非全日制用工`（「非全日制用工双方当事人可以……」——概念作定语）、
`#72 集体合同`（「集体合同中……标准不得低于……」——方位短语）。

仍被误杀的 5 条真边集中在两种句法：并列主语（「债权人与保证人可以约定」）与
定语中心语（「委托开发合同的委托人应当……」）。它们与「合伙人的债权人不得代位」这类假边
只差一个中心语判定，加规则容易两头跑，这一轮不动。

## 这个 0.936 能写进 README 吗

不能，还差一步。样本的 100 条是从**旧**的 819 条里抽的，改后保留的 47 条只是它的子集，
所以 0.936 是「对旧样本中幸存部分的再判定」，不是新集合的独立抽样。要得到可引用的数字，
需要用 `--sample 100` 在**新**的 505 条上重新抽一批、重新人工盲标。

`defines_human_labels.csv` 保持空白未填；`mentions_typed.jsonl` 也未覆盖——
重生成是这一步，需要显式执行：

```bash
DEFINES_GUARD=1 .venv/Scripts/python.exe app/__002__extract/__003__edge_typing.py
```

覆盖后 `graph.json` 与依赖 `DEFINES` 的下游评测（`scripts/eval_*.py`）都会随之变化，应一起重跑。
